# English Path

Приложение для изучения английского с интервальным повторением (до версии 2.0 — Oxford Cards). Разделы:

- **Практика** — англо-русские карточки 3000 слов закреплённой британской редакции Oxford 3000: A1 — 900, A2 — 800, B1 — 700, B2 — 600. Отдельные значения одного написания представлены разными карточками: всего 2979 различных написаний. Плюс моды по фильмам.
- **Глаголы** — 148 неправильных глаголов: по русскому переводу вспомнить или ввести одну форму — Past Simple или Past Participle (раздел «Неправильные глаголы» ниже).
- **Грамматика** — справочник пяти времён и упражнение «Определи время» (раздел «Грамматика» ниже).

## Установка в Windows

Скачайте **English-Path-Setup.exe** из [последнего релиза](https://github.com/MaybeKrat/english-path/releases/latest) и запустите. Установщик для **Windows x64** ставит приложение в `C:\Program Files\English Path` (папку можно выбрать; Windows попросит права администратора), создаёт ярлык в меню «Пуск», по галочке на отдельном шаге — на рабочем столе, и пункт в «Установка и удаление программ». Оформление — в цветах приложения: картинки рисует `npm run build:installer-images` из `desktop/installer/*.svg` под масштаб Windows 125%, тексты и шаги — `desktop/installer.nsh`. Новая версия ставится поверх старой тем же установщиком; прогресс при этом не трогается. Ярлык старого переносного `Oxford Cards.exe` на рабочем столе установщик удаляет. Приложение работает в отдельном окне; повторный запуск возвращает уже открытое окно.

Записи произношения в установщик не входят: после первого запуска приложение в фоне скачивает их одним файлом (около 80 МБ) из отдельного релиза GitHub `voices-<хеш>` в `%LOCALAPPDATA%\English Path\voices` и проверяет SHA-256. Прерванная загрузка продолжается с того же места, при ошибке приложение повторяет попытку само (через 30 с, 1, 5 и 15 минут). Пока записи не скачаны, слова читает голос Windows. Ход загрузки виден в левой панели — блок «Озвучка» с процентом и полоской (по просьбе Ивана 09.11.2026; нажатие открывает настройки, после загрузки блок исчезает) — и строкой в **Настройки → Голос**. Новая версия приложения скачивает пакет заново, только если записи изменились.

При первом запуске English Path копирует прогресс Oxford Cards из `%APPDATA%\Oxford Cards` в `%APPDATA%\English Path`; старая папка остаётся нетронутой как резервная копия. Если Oxford Cards в этот момент открыта и копирование не удалось, приложение просит закрыть её и запустить English Path снова.

Верхняя полоса окна пустая и служит для перетаскивания; цвет левой панели доходит до верхнего края. Справа доступны сворачивание, разворачивание и закрытие. Начальный размер — 1400 × 920 логических пикселей с учётом масштаба Windows. На небольшом мониторе приложение открывается развёрнутым в доступной рабочей области. Слева — меню, серия занятий по дням недели и доля начатых слов Oxford 3000 по уровням; на «Практике» карточка занимает всю доступную высоту, а в невысоком окне шрифты и кнопки становятся компактнее. В узком окне меню переезжает вниз.

Карточки и шрифты входят в установку; интернет нужен для фоновой загрузки записей произношения и переходов к внешним словарям. Записи лежат в репозитории (`public/voices/`), веб-версия берёт их оттуда. Слово без записи читает установленный английский голос Windows.

В **Настройки → Внешний вид → Тема оформления** доступны «Как в Windows», «Светлая» и «Тёмная». По умолчанию приложение следует системной теме приложений Windows и переключается сразу, без перезапуска, вместе с верхней панелью окна. Ручной выбор сохраняется между запусками и в резервных копиях. Старый прогресс автоматически получает системный режим. В веб-версии системная тема определяется браузером.

В приложении для Windows там же есть **Масштаб** — размер текста и кнопок от 75 до 300% (по умолчанию 100%); крупные шаги 250 и 300% — чтобы заниматься на расстоянии от экрана. Выше 100% вместе с интерфейсом растёт курсор мыши в окне приложения; у самого правого и нижнего края окна Chromium показывает вместо него обычный курсор Windows. Полоса заголовка окна от масштаба не растёт. В режиме фокуса слово, перевод и пример подстраиваются под размер карточки и при большом масштабе занимают свободное место; счётчики под полоской занятия в этом режиме скрыты. Быстро менять его можно как в браузере: Ctrl+колесо мыши, Ctrl+плюс, Ctrl+минус, Ctrl+0 возвращает 100%. Раскладка подстраивается под масштаб так же, как под размер окна. Выбор сохраняется между запусками и в резервных копиях. В веб-версии настройки нет: там работает масштаб браузера.

Прогресс приложения хранится в `%APPDATA%\English Path`, отдельно от программы. Закрытие окна полностью завершает приложение; при следующем запуске прогресс восстанавливается. Обновление и удаление программы прогресс не удаляют. Не удаляйте этот каталог, если хотите сохранить обучение.

Для переноса прогресса между компьютерами или из веб-версии используйте **Настройки → Скачать копию**, затем **Восстановить из файла** в приложении на другом устройстве. Веб-версия и приложение для Windows используют разные хранилища.

Самостоятельная сборка установщика после клонирования проекта и установки зависимостей, описанных ниже:

```powershell
npm run build:voice-pack   # release/English-Path-voices.pack и desktop/voice-pack.json
npm run build:setup        # release/English-Path-Setup.exe
```

`build:voice-pack` упаковывает `public/voices/` в один файл (формат описан в `desktop/voice-pack.cjs`) и записывает в `desktop/voice-pack.json` адрес, размер и SHA-256. Одинаковые записи дают одинаковый файл и тот же релиз `voices-<хеш>`, поэтому пакет перезаливается только после изменения записей. Выкладку описывает `AGENTS.md` проекта.

Записи произношения всех карточек и неправильных глаголов лежат в `public/voices/` (около 90 МБ). После добавления карточек, например нового фильма, недостающие записи дописывает `python scripts/build-voices.py` (нужны `pip install edge-tts` и интернет; уже записанные пропускаются); затем пакет пересобирается.

Разработчикам: `npm run desktop` открывает последнюю сборку `dist` через Electron. `npm run build` обновляет эту сборку. Обычному пользователю эти команды не нужны.

Иконка хранится в `public/favicon.svg`. Команда `npm run build:icons` создаёт из этого же векторного исходника PNG и Windows ICO с размерами от 16 до 256 px. Сборка установщика запускает её автоматически, поэтому иконки сайта и приложения совпадают.

## Запуск веб-версии для разработки

Нужен **Node.js 24** с npm. В PowerShell:

```powershell
git clone https://github.com/MaybeKrat/english-path.git
cd english-path
npm ci
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). Оставьте терминал работающим; `Ctrl+C` останавливает сервер. Первичная установка пакетов требует доступа к интернету. Словарь уже включён в проект, поэтому для обычной практики загрузка слов из сети не нужна.

В Windows также можно запустить `Start-App.ps1` из каталога проекта:

```powershell
.\Start-App.ps1
```

Скрипт установит зависимости через `npm ci`, если папки `node_modules` ещё нет, и запустит сервер на том же адресе. Если порт 5173 занят уже запущенным экземпляром, откройте его или остановите прежний сервер.

## Как заниматься

На странице «Практика» вспомните перевод, откройте ответ и оцените себя. Сначала идут карточки, срок которых наступил, затем новые слова выбранных уровней: от A1 к B2, тематическими группами внутри каждого уровня. Темы проходят автоматически: «Люди и семья», «Дом и быт», «Еда и напитки» и далее — всего 26 тем. Название темы видно на карточке и в подробностях слова. Когда все новые слова темы изучены, начинается следующая; после перезапуска занятие продолжается с оставшихся слов. Уже изученные карточки сохраняют своё расписание и не проходят заново как новые.

Дневной лимит относится только к новым карточкам; повторения не ограничены. Настройки позволяют менять лимит, уровни, направление перевода и автоматическое произношение. «Словарь» сохраняет алфавитный порядок для поиска. Тематическая разметка — независимая группировка приложения, не официальная классификация Oxford.

Когда занятие закончено, экран «Готово на сегодня» показывает итог дня: сколько карточек пройдено, примерное время, долю ответов «Помню» и «Легко», число новых слов и когда следующее повторение. На кнопке «Трудные ещё раз» — сколько слов сегодня получили «Не помню» или «Сложно». Кнопка **«Ещё 10 слов на сегодня»** добавляет следующую порцию новых карточек выбранных уровней. Её можно нажимать снова после каждой порции; если осталось меньше десяти слов, кнопка покажет их количество. Обычный лимит в настройках не меняется. Добавленные слова доступны до конца текущего местного дня, в том числе после закрытия приложения; завтра снова действует обычный лимит. Уже изученные дополнительные слова сохраняются и участвуют в интервальном повторении.

| Действие | Клавиша | Следующий интервал |
| --- | --- | --- |
| Открыть ответ | Пробел | — |
| «Не помню» | 1 | 1 минута |
| «Сложно» | 2 | При первой оценке новой карточки — 1 час; далее не менее 1 дня, предыдущий интервал × 1,2, но не дольше «Помню» |
| «Помню» | 3 | 1 день, затем 6 дней, затем интервал × коэффициент лёгкости. После «Не помню» или часа «Сложно» — снова с 1 дня |
| «Легко» | 4 | Около 4 дней (3–5 с учётом разброса) и всегда хотя бы на день дольше «Помню»; предыдущий интервал × коэффициент лёгкости × 1,3 |

Над карточкой — полоска занятия: сколько ответов уже дано сегодня, сколько осталось повторений и новых слов и примерное время до конца (по вашему обычному темпу ответов). Там же переключатель мода фильма, кнопка автоматического произношения — она открывает список режимов: не произносить, один раз при показе карточки или повторять каждые 5, 10, 15, 20 или 30 секунд (на кнопке тогда «⟳ 10 с» и т. п.); тот же список — **Настройки → Произносить автоматически**. Повтор звучит, пока окно приложения активно и перевод не открыт, и только в направлении «Английский → русский», — и режим фокуса: он прячет боковые колонки и оставляет только карточку (выход — та же кнопка или Esc). Справа сводка «Сегодня»: новые слова из дневной цели, повторения, доля ответов «Помню» и «Легко» за день; под ней число повторений на завтра и блок «Мод фильма»: до двух фильмов — включённый (или последний, который вы учили) и тот, что ближе всего к просмотру. Нажатие на карточку фильма включает его, повторное нажатие на включённый фильм (он обведён зелёным) выключает мод. У каждого фильма одинаково показаны доля изученных слов и доля понятной речи; в них входят и уже выученные слова Oxford, поэтому фильм может быть частично знаком ещё до включения мода.

Если слово не вспоминается, клавиша **E** (или ссылка под карточкой) показывает английский пример до ответа; в направлении «Русский → Английский» само слово в примере скрыто. После ответа пример показан с выделенным словом, а под переводом — последние оценки этой карточки. Кнопка **«Трудные ещё раз»** на экране «Готово на сегодня» прогоняет сегодняшние трудные слова повторно: ответы «Ещё раз» (1) и «Помню» (2) в этом прогоне не меняют расписание.

Клавиши 1–4 работают после открытия ответа. Горячие клавиши не перехватывают ввод в текстовых полях и списках; на кнопке или ссылке Пробел сохраняет обычное действие браузера. «Отменить» возвращает состояние до последней оценки.

Используется модификация [SM-2](https://www.super-memory.com/english/ol/sm2.htm), а не точная реализация исходной шкалы из шести оценок. Начальный коэффициент лёгкости — 2,5; оценки меняют его в пределах 1,3–5. Интервалы от одного дня округляются вверх. Часовой интервал «Сложно» применяется только при самой первой оценке карточки; уже назначенные повторения не меняются. Ошибка сбрасывает последовательность успешных ответов; после «Не помню» успешный ответ «Помню» начинает её с одного дня. «Не помню», пока слово ещё ни разу не вспомнилось, коэффициент лёгкости не снижает: промахи при первом знакомстве не делают слово «трудным» навсегда. Карточка считается закреплённой при интервале от 21 дня.

Новая карточка расходует дневной лимит при первой оценке, даже если ответ — «Не помню». Лимит и серия занятий считаются по местной календарной дате устройства. Интервалы от одного дня считаются в учебных днях: учебный день начинается в 4:00, и повторение приходит в 4:00 нужного дня; ответ ночью до 4:00 относится к предыдущему дню. Интервалы от трёх дней получают разброс ±5%, но не меньше дня — чтобы слова, начатые в один день, не возвращались все вместе; у одной карточки при одном ответе разброс всегда одинаковый, поэтому срок на кнопке совпадает с назначенным. Одна минута после «Не помню» и час «Сложно» отсчитываются от времени ответа. Дневной лимит новых слов и серия занятий по-прежнему считаются по календарной дате (с полуночи). Очередь обновляется каждые 15 секунд и при возвращении в окно приложения.

### Моды по фильмам

Мод выбирается прямо на «Практике»: кнопка «Выбрать фильм» над фильмами справа (или переключатель над карточкой) открывает меню: что включено сейчас, два фильма, которые ближе всего к просмотру (подборка меняется раз в день), «Выключить мод» и «Все фильмы». У каждого фильма в меню — доля изученных слов и понятной речи с полоской и кнопка «Включить». «Все фильмы» открывают окно со всеми фильмами: поиск по русскому и английскому названию, фильтр «Начатые», сортировка «Ближе к просмотру» или по названию. На каждом фильме видно, какая доля его речи понятна уже сейчас по выученным словам и сколько слов осталось выучить. Выбор также доступен в **Настройки → Мод фильма**. Сейчас доступны «Дюна» и «Зверополис» (Zootopia), в обоих модах — обе части. Одновременно активен один мод. Новое слово, которое есть в нескольких фильмах, — одна карточка с общим прогрессом. Пока в моде есть неначатые слова, дневной лимит новых слов и кнопка «Изучить сегодня ещё 10 слов» берут только их, от частых в фильме к редким; выбранные уровни на слова мода не влияют. Потом продолжается обычная очередь Oxford. Повторения идут как обычно.

В мод входят все слова фильма из Oxford 3000 — это те же карточки с общим прогрессом, — а также новые слова и термины мира фильма. Вместо уровня у новых карточек метка «Дюна», у терминов — «Термин Дюны» и короткое пояснение. В «Словаре» их можно выбрать отдельным фильтром по названию фильма. При выключении мода новые слова фильма пропадают из словаря и повторений, но их прогресс сохраняется и возвращается при включении.

Слово мода считается изученным, если последний ответ на нём — «Помню» или «Легко». На «Практике» карточка фильма показывает долю изученных слов мода и долю речи фильма, которую они покрывают (частые слова весят больше). На «Прогрессе» у фильмов своя вкладка «Фильмы»: по каждому фильму доля понятной речи (всего и по частям), доля изученных слов и сколько осталось; включённый фильм выделен и стоит первым, остальные можно включить оттуда же. Общая статистика Oxford 3000 новые карточки фильма не учитывает.

«Словарь» содержит поиск по английскому слову и русскому переводу, фильтры уровня, стадии памяти и темы. В таблице у каждого слова — стадия памяти (от 0 до 4 делений) и дата следующего повторения. Подробности открываются панелью справа: все значения слова с одинаковым написанием, пример, история ответов, интервал и число ошибок.

«Прогресс» — по центру окна, две вкладки:

- «Oxford 3000» — текущий уровень (первый, где начаты не все слова) и путь A1 → A2 → B1 → B2 → 3 000 с отметкой «вы здесь»: пройденные уровни закрашены, под каждым — сколько слов начато. Ниже — следующая остановка (ближайшая сотня начатых слов и примерно сколько дней занятий до неё при текущем лимите новых слов; когда начаты все, — сотня слов с интервалом от 7 дней), серия дней подряд и доля ответов «Помню» и «Легко» за 7 дней;
- «Фильмы» — прогресс по каждому фильму (см. выше).

В левой панели под серией дней — тот же путь в уменьшенном виде: текущий уровень, точки A1–B2 и сколько слов Oxford 3000 изучено (последний ответ — «Помню» или «Легко», как и для фильмов). Нажатие открывает «Прогресс».

В приложении для Windows слова звучат записями британских нейроголосов Microsoft — Ryan (по умолчанию) или Sonia, выбор в **Настройки → Голос**. Записи всех карточек Oxford 3000, модов фильмов и неправильных глаголов сделаны заранее; после фоновой загрузки (см. «Установка в Windows») звук начинается сразу и не зависит от голосов Windows. Слово без записи заранее полностью синтезируется в WAV установленным английским голосом Windows. Оба варианта проигрываются через Web Audio. Записи хранятся только в памяти; подготовка записи сама по себе не включает звук и не раскрывает ответ обратной карточки. Перед первым воспроизведением и после простоя добавляется короткое беззвучное начало записи для запуска аудиовыхода. Этот приём не гарантирует устранения аппаратной задержки конкретных наушников.

Кнопка звука подсвечивается во время подготовки и речи; повторное нажатие проигрывает запись с начала. Быстрые нажатия объединяются в последний запрос. При смене карточки, закрытии подробностей или сворачивании приложения прежняя речь останавливается. Если подготовка или воспроизведение не удаются, приложение сообщает об ошибке и позволяет повторить нажатие. В веб-версии используется отдельный контроллер голосов браузера; наличие голоса и необходимость сети зависят от браузера.

### Неправильные глаголы

Раздел **«Глаголы»** в меню: 148 неправильных глаголов (`src/data/irregular-verbs.json`), британские формы; где обе формы обычны, показаны обе: «learnt / learned», «was / were». На карточке — русский перевод глагола (у близких по смыслу глаголов — с уточнением: «сказать, произнести (слова)» и «говорить (на языке), выступать»); карточка спрашивает одну форму (решение Ивана 09.11.2026): Past Simple и Past Participle по очереди — при чётном числе прежних ответов на глагол Past Simple, при нечётном Past Participle, так что каждое повторение меняет форму. Её можно ввести в поле или вспомнить про себя. Если непонятно, какой глагол имеется в виду, клавиша **E** показывает пример по-русски. Enter (или Пробел вне поля) открывает ответ: все три формы, спрошенная выделена, пример с выделенной формой и переводом, кнопка произношения трёх форм. Введённая форма помечается верной или неверной; любая из допустимых форм засчитывается. Затем ответ оценивается клавишами 1–4 по тем же правилам интервалов, что и слова; после ввода приложение подсвечивает подходящую оценку («Помню» или «Не помню»), выбор остаётся за вами. «Отменить» возвращает последнюю оценку глагола.

Новый глагол открывается, когда его слово выучено в «Практике» (последний ответ на карточке — «Помню» или «Легко»); связь глагола с карточками — поле `cards` в данных. Уже начатые глаголы продолжают повторяться, даже если слово потом забыто. 22 глагола, которых нет ни в Oxford 3000, ни в модах фильмов (burst, flee, sew и др.), пока не открываются; в таблице у закрытых глаголов замок. Открытые глаголы идут от A1 к B2, внутри уровня — от частых к редким; дневной лимит у них свой — **Настройки → Новых неправильных глаголов в день** (по умолчанию 5). Прогресс глаголов хранится отдельно от слов и входит в резервную копию: он не расходует лимит новых слов и не влияет на статистику Oxford 3000, но занятия глаголами продлевают серию дней. Под карточкой — таблица всех глаголов с поиском и стадией памяти; нажатие на строку произносит три формы. Уровень взят из Oxford 3000; 28 глаголов вне этого списка получили B2. Переводы и примеры подготовлены с помощью ИИ и не прошли редакторскую проверку.

### Грамматика

Раздел **«Грамматика»**, две вкладки.

**Справочник** — пять времён, выбранных Иваном 09.11.2026: Present Simple, Present Continuous, Past Simple, Present Perfect, Future Simple. Сверху сводная таблица (когда употребляется, формула, пример), ниже по каждому времени: когда его используют, как строятся утверждение, отрицание и вопрос, слова-подсказки и частые ошибки русскоговорящих. Тексты — `src/grammarReference.ts`.

**Определи время** — упражнение: английское предложение, нужно выбрать его время (клавиши 1–5). После ответа глагол выделяется, слово-подсказка подчёркивается, показываются объяснение, перевод и ссылка на правило в справочнике; Enter или Пробел — следующее предложение. Раунд — 10 предложений, в конце — итог и список ошибок. Предложения с ошибкой в последнем ответе приходят в следующем раунде первыми, затем ещё не встречавшиеся, затем давно виденные. В наборе 200 предложений, по 40 на время (`src/data/grammar/tense-sentences.json`, подготовлены с помощью ИИ). Ответы сохраняются в прогрессе и резервной копии, продлевают серию дней; в справочнике у каждого времени видно, сколько из последних 20 предложений этого времени определено верно.

## Прогресс и резервные копии

В Windows-приложении настройки, статистика и расписание повторений хранятся в локальном профиле `%APPDATA%\English Path`, отдельно от программы. В веб-версии используется `localStorage` текущего браузера. Облачной учётной записи и синхронизации между устройствами нет. В настройках используйте «Скачать копию» и «Восстановить из файла». Перед заменой прогресса приложение проверяет JSON и просит подтвердить восстановление.

В веб-версии данные привязаны к адресу сайта, включая порт: `127.0.0.1`, `localhost` и сервер предпросмотра на порту 4173 имеют разные хранилища. Для переноса между ними используйте резервную копию. Очистка данных сайта удаляет прогресс веб-версии; удаление профиля `%APPDATA%\English Path` удаляет прогресс Windows-приложения.

Открытые вкладки одного адреса получают изменения через событие `storage`. Перед сохранением приложение сверяет исходное состояние и просит повторить действие, если другая вкладка уже изменила прогресс. В браузерах с Web Locks записи дополнительно выполняются по очереди под общей блокировкой. Без Web Locks остаётся проверка состояния, но строгая блокировка одновременных записей недоступна.

Если сохранённые данные повреждены, приложение блокирует их автоматическую перезапись. В настройках можно скачать исходные данные для восстановления, загрузить исправную копию либо подтвердить начало заново.

## Сборка и проверки

```powershell
npm run build
npm test
npm run check:data
```

`build` проверяет TypeScript и создаёт статическую сборку в `dist`. `test` запускает тесты планировщика, хранения, озвучивания, начальных размеров окна и ограничений десктопной оболочки через встроенный `node:test`. `check:data` проверяет 3000 записей, уникальные идентификаторы, структуру, непустые русские переводы и распределение CEFR закреплённой редакции. Проверка данных не оценивает лингвистическую точность переводов.

Для просмотра готовой сборки выполните `npm run preview` и откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сценарии проверок описаны в [QA.md](QA.md).

## Источники и изменение словаря

### Подготовка к просмотру «Дюны»

30.10.2026 Иван попросил сопоставить английскую лексику фильмов «Дюна» (2021) и «Дюна: Часть вторая» (2024) со словарём приложения. Исследование и частотный отчёт с поиском находятся локально в `work/dune-vocabulary/dune-vocabulary.html`; исходные ссылки, методика, ограничения и скрипты — рядом. По доступным транскриптам Springfield словарь покрывает около 87% употреблений, примерно 93% после исключения выделенных имён и терминов мира. Это не оценка знания слов Иваном или понимания речи. Транскрипт второй части пропускает некоторые реплики на вымышленных языках, поэтому цифры не описывают весь текст фильма. На основе исследования 30.10.2026 собран набор мода «Дюна»: 1086 карточек Oxford, 300 новых слов и 41 термин. Источники описаны в [DATA-SOURCES.md](DATA-SOURCES.md). Как пользоваться модом — раздел «Моды по фильмам».

### Данные словаря

Сверка 31.10.2026 с первоначальным частотным отчётом: все 14 рекомендованных слов представлены в моде, причём `reverend` — в карточке `Reverend Mother`. Из 341 новой карточки 328 совпадают с написаниями отчёта напрямую, остальные 13 соответствуют составным терминам или исправленным формам слов. Это проверка состава, не редакторская проверка переводов. Детали: `work/dune-vocabulary/comparison-2026-10-31.json`. Старый HTML-отчёт отражает только базовый Oxford 3000 и не учитывает добавленный мод.

Английские слова и уровни взяты из закреплённой опубликованной редакции Oxford 3000; это не утверждение об использовании самой последней редакции. **Русские переводы и примеры неофициальные, подготовлены с использованием ИИ и не прошли полную редакторскую проверку.** Независимое приложение не связано с Oxford University Press.

Источники, версии, хеши исходных файлов, атрибуция и воспроизводимый импорт перечислены в [DATA-SOURCES.md](DATA-SOURCES.md). Для сомнительных переводов на карточках есть ссылка на Cambridge Dictionary.
